# Hr-Analytics-Performance-Dashboard.
HR &amp; Training Analytics Dashboard in Microsoft Excel transforms raw HR data into clear executive insights. Features cleaned data with conditional formatting, 5 core KPI cards, 7 custom chart types (Donut, Column, Bar, 3D Pie, Stacked Bar, Line, Area), and 4 global slicers for interactive real-time analysis of L&amp;D costs, outcomes, and satisfaction.
